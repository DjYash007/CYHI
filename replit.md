# CYHI Hackathon Starter

## Run commands

- `npm run dev` starts the backend and frontend together.
- The backend listens on port `5000`.
- The Vite frontend listens on port `5173`.
- `npm run build` creates the frontend production build.
- `npm run install:all` installs dependencies in both service directories.

## Replit preview

The `Start application` workflow runs the Vite frontend on port `5000` so it
can be opened in the Replit preview. This is separate from the full local
`npm run dev` command because the backend and frontend use different ports.
