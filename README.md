# CYHI Hackathon Starter

A minimal 24-hour hackathon starter monorepo with a Node/Express backend,
React/Vite frontend, and Chrome Extension Manifest V3 shell.

## Getting started

```bash
npm install
npm run install:all
npm run dev
```

The backend runs on `http://localhost:5000` and the Vite frontend runs on
`http://localhost:5173`.

The Chrome extension can be loaded from `extension/` using Chrome's
**Load unpacked** option in `chrome://extensions`.
